# Inspector

The panel on the right that looks into the session: its changes, what the agent did, its files and its terminal, one tab at a time. It is closed until you open it from the top bar's **Inspector** button.

The consumer provides the tabs that apply (Changes in a git repository, Activity with a session, Files and Terminal with a folder), the panel of the current tab, and the remembered width.

- **Frame.** `surface-1` with a `border` on its left edge, `ui` text in `fg`. A 48px header (12px in on the left, 8px on the right, a `border` under it) holds the `Tabs` strip (Changes, Activity, Files, Terminal, always in that order, with the count of changed files on Changes) and **Close inspector**, a 24px icon button.
- **Width.** It opens 380px wide. Its left edge is a separator named "Resize inspector": drag it, or use Left and Right, between 320 and 720px (560 on the Terminal tab), 16px a step. While you point at it or drag it, it shows a 3px `border-strong` line and a 10×36 grip. The width is remembered on this Mac.
- The Terminal tab widens it to at least 560px while it shows, and leaving the tab brings the remembered width back. Closing the tab or the inspector never ends a shell.
- **Activity.** 16px in, 16px between its parts.
  - **Intro.** "This is <Agent>'s own report of what it did. Rewinding the chat removes its entries too." in `caption` `fg-subtle`, after a 12px info icon.
  - **Filters.** All, Files, Commands, Permissions, as 24px ghost chips with their counts in `fg-subtle`; the pressed one is filled `surface-hover`.
  - **Unreported changes.** When git shows changed files the agent did not report, a card on `attention-surface` with an `attention-border` edge and `radius-lg`. It holds a 14px warning icon in `status-attention`, the title "2 files changed that <Agent> didn't report" at 600, the paths in mono `caption` `fg-secondary`, what it compared ("Compared with uncommitted changes."), and **Show in Changes**, which opens the Changes tab. There is no card when nothing is unreported.
  - **Turns.** The entries are grouped by the prompt they answered, newest turn first, each turn's entries in the order the agent did them. A heading reads "Turn 3", how long ago you sent it, and "· <prompt>" cut to one line. What came before your first prompt (an imported history) is "Earlier".
  - **Rows.** On a 1px `border` rail, each entry has a 9px dot: filled `status-running` when it went through, edged `danger` when it failed or you refused it, `status-running` while it runs, `status-attention` while it waits for you, and `border-strong` when it did not finish.
    - **Verb.** A 52px column in `ui-sm` `fg-muted`: past tense only for a tool that completed ("Edited", "Ran", "Read"), otherwise what the tool was for ("Edit", "Run"), so a row never claims an action that may not have happened; a permission reads "Asked".
    - **Target.** The path or command, mono `caption` `fg-secondary`, on one line. A permission reads "to run <command>".
    - **Result.** On the right in `caption`, as a link to the message: "Done" and "Allowed" in `fg-subtle`, "Failed" and "You denied" in `danger`, "Waiting for you" and "Not answered" in `status-attention`, "Running" in `status-running`, "Did not finish" in `fg-muted`. The link's name adds the option you picked ("Allowed (Allow always)"), and the row's tooltip holds the whole command.
  - **Heading.** A turn's heading is "Turn 3" (or "Earlier") alone; the time and the prompt sit beside it, so a long prompt is never read as the heading.
  - At most the newest 500 entries show; "N older entries are not shown." says how many it leaves out.
- **Files.**
  - **Header.** 12px 12px 8px 16px, no border. The folder's name in `ui` at 600, over its path in mono `caption` `fg-subtle`. **Refresh files** and **Reveal in Finder** (an external-arrow icon) are 26px icon buttons.
  - **Filter.** A 30px field with `radius-lg`, a `border-strong` edge on `surface-2`, and a 14px search icon.
  - **Tree.** Rows are 26px, `radius-sm`, in mono `ui-sm` `fg-secondary`, filled `surface-hover` in `fg` on hover. A folder sits 4px in plus 16px a level, with a 12px chevron in `fg-subtle` and a closed 14px folder icon in `fg-muted` (the chevron says whether it is open). A file sits past its folder's chevron, so the icons line up, with a 14px file icon in `fg-subtle`.
  - **Markers.** On the right in a 12px slot at `micro` 600: "M" (modified or renamed) in `status-attention`, "A" (added or untracked) in `status-running`, and "•" in `status-attention` on a folder that holds changes, deletions included. Each is in words for a screen reader ("Modified", "Added", "contains changes"). The markers come from the diff stats against HEAD that the top bar's chip already reads.
  - **Add to prompt.** A row you point at or tab into shows a 20px pill before its marker: a 10px plus and "Add to prompt", with a `border-strong` edge.
- **File viewer.** Clicking a file opens it read only in the Files tab, which then widens to at least 560px like Terminal. Another folder closes the viewer.
  - **Path bar.** 44px: **Files** (a 26px ghost button with a chevron-left, in `fg-secondary`), the path in mono `caption` `fg-subtle` with the file's name in `fg` and its marker at 600, then **Add <file> to prompt**, **Open in editor** (the file's default app) and **Copy path** as 26px icon buttons.
  - **Meta bar.** Its own 32px row in `caption` `fg-subtle`: "TypeScript · 120 lines · Read only", plus **Mark changed lines** in `fg-secondary` (only for a changed file, on by default).
  - **Body.** On a `bg` well, 10px top and bottom, 12px mono on 20px lines in `fg-secondary`. Line numbers sit in a 40px gutter in `fg-subtle`, then a 3px bar beside each changed line (`status-running` added, `status-attention` modified, from the file's diff against HEAD), 10px from the code. Syntax is monochrome: keywords `fg` at 500, strings `fg-muted`, comments `fg-subtle` italic.
  - **Selecting lines** tints them `line-selected`, their numbers in `fg`, and shows **Add lines A–B to prompt** in a small `surface-3` card with `shadow-popover` under the selection's last line, which scrolls with the code. It inserts the path, the range and the lines fenced in the file's language, when the message box can take it, as for Reply.
  - **Files it cannot show.** A binary file (a NUL in the first 8 KiB, or not UTF-8), one over 1 MB, or one that is gone shows a sentence instead of content.
- **Terminal.** While it holds shells the whole tab is `terminal-bg`, in both themes; without one (no shell yet, or one starting) it keeps `surface-1`.
  - **Strip.** 36px, 12px in on the left, with a `terminal-surface` line under it. Each shell is a 24px tab named by its shell ("zsh", then "zsh 2"); the selected one is filled `terminal-surface` in `terminal-fg-strong` and shows the folder's name in mono `caption` `terminal-fg-muted` (`terminal-fg-subtle` would be under 4.5:1 there), the others are `terminal-fg-muted`. Each tab keeps a small close button. **New terminal**, a 24px icon button with a 12px plus, follows the tabs (outside the tablist). The strip's focus rings use the fixed `terminal-fg-muted`, since the theme's ring turns dark in light mode.
  - **Size.** On the right, the selected shell's size as xterm last fit it ("80 × 38") in `caption` `terminal-fg-subtle`; nothing until the first fit.
  - **Terminal.** 12px top and bottom, 14px at the sides, 12px mono on 18px rows with a block cursor. A shell that exited says so in a `surface-1` bar under it, with **Start a new shell**.
- When the window is too narrow for the sidebar (256px), the inspector and a 560px chat, the inspector showing wider (opening it, or switching to Terminal) hides the sidebar.
- The panels inside have no width, edge, header or close button of their own.
- The full diff review (from the top bar's diff chip, or **Open the diff** in Changes) opens in the chat's place, with the changed files listed on its left. **Shrink**, or adding comments to the message, puts it beside the chat in the inspector's place: opening one closes the other, so the chat is never squeezed between them. The review takes the chat's place only for the session (or draft) it opened in: another session shows its own chat, with the review beside it.
- A tab that stops applying (another folder, a new-session draft) hides the inspector rather than showing an empty panel; it shows again when the tab applies again.
