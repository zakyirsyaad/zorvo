# Agent logos

`claude-code.svg`, `qwen.svg` and `codex.svg` are `claudecode-color.svg`,
`qwen-color.svg` and `codex-color.svg` from
[@lobehub/icons-static-svg](https://github.com/lobehub/lobe-icons) 1.95.1 (MIT).

They are shown only to name the agent a session runs; the logos and names
are trademarks of their owners (Anthropic, Alibaba Cloud, OpenAI). Agents
without an official logo here get a generic icon.

`gemini.svg` is the Gemini CLI icon from the ACP registry (`src-tauri/resources/registry-icons.json`), with its fill set to the page's text colour so it shows on the landing page's dark tiles. Used only on the website; the logo and name are a trademark of Google.
